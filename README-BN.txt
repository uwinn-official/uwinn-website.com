UZONE MEMBER PORTAL — বাংলা নির্দেশিকা

এই ZIP ফাইলে আছে:
- index.html : ওয়েবসাইটের পেজ
- style.css  : ডিজাইন ও মোবাইল-ফ্রেন্ডলি লেআউট
- app.js     : ডেমো রেজিস্ট্রেশন/লগইন

কম্পিউটারে চালাতে:
1. ZIP ফাইল Extract করুন।
2. index.html ফাইল Chrome/Firefox-এ খুলুন।

ইন্টারনেটে প্রকাশ করতে:
1. Netlify, GitHub Pages বা নিজের হোস্টিংয়ে ফাইলগুলো আপলোড করুন।
2. নিজের ডোমেইন যুক্ত করতে চাইলে ডোমেইন ও হোস্টিং কিনে DNS সেট করুন।

গুরুত্বপূর্ণ নিরাপত্তা নোট:
এই সংস্করণটি শুধুই ফ্রন্ট-এন্ড ডেমো। রেজিস্ট্রেশন তথ্য ব্রাউজারের localStorage-এ রাখা হয় এবং পাসওয়ার্ড নিরাপদভাবে সংরক্ষিত নয়। বাস্তব ব্যবহারকারীর তথ্য, আসল লগইন, পাসওয়ার্ড রিসেট, ইমেইল যাচাই, অ্যাডমিন প্যানেল বা সার্ভার-ভিত্তিক সদস্য ব্যবস্থাপনার জন্য ব্যাকএন্ড, ডেটাবেস, নিরাপদ পাসওয়ার্ড হ্যাশিং, অনুমতি যাচাই এবং HTTPS যোগ করতে হবে। এই ডেমোকে বাস্তব অ্যাকাউন্ট ব্যবস্থাপনায় ব্যবহার করবেন না।

ব্র্যান্ড “UZone” একটি নমুনা নাম; আপনার পছন্দের নাম ও লোগো দিয়ে বদলাতে পারবেন।
